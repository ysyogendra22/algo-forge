# Searching Fundamentals

#### 1. What is Searching?

Searching means finding a specific element in a collection.

Example:

```text
Array  = [10, 20, 30, 40]
Target = 30
Result = Index 2
```

#### 2. Why Searching?

1. Check if an element exists.
2. Find the position of an element.
3. Retrieve required data.

#### 3. Basic Terms

1. **Target / Key** — Element we want to find.
2. **Search Space** — Data where we search.
3. **Index** — Position of the element.
4. **Match** — Target is found.

#### 4. Sorted vs Unsorted

**Sorted:**

```text
[10, 20, 30, 40]
```

**Unsorted:**

```text
[30, 10, 40, 20]
```

Whether data is sorted is important when choosing a searching algorithm.

#### 5. Before Searching

Check:

1. Is the data sorted?
2. What target are we looking for?
3. Do we need the value, index, or just existence?
4. Can duplicates exist?

#### 6. Must Remember

1. Searching = **finding a target**.
2. Understand the **search space**.
3. Check whether data is **sorted**.
4. Choose the searching algorithm based on the data.
